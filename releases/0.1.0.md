## Quiet Car 0.1.0

First experimental release of Quiet Car, a desktop Obsidian plugin that automatically requests native Reader mode for web pages in the core Web Viewer.

### Features

- Uses Obsidian's native Reader and Web Viewer—no separate extraction engine or saved article copies.
- Requests Reader on new full-document visits, reloads, and full-document history navigation.
- Respects manual Reader/Original choices for the current visit.
- Provides an automatic-mode toggle and stores only that preference.
- Uses `quiet-car` as the plugin ID and installation folder.

### Installation

1. Use a dedicated test vault with **Obsidian desktop core 1.14.4**.
2. Download `main.js` and `manifest.json` from this release.
3. Place both files in `<vault>/.obsidian/plugins/quiet-car/`.
4. Enable the core **Web Viewer**, then the **Quiet Car** community plugin.
5. Manually close and reopen existing Web Viewer tabs after enabling or reloading the plugin.

### Limitations

- Experimental prerelease, not a claim of full release readiness.
- Desktop core **1.14.4 only**; other versions leave automation unavailable. No mobile support.
- SPA route changes are not automated; use the native Reader button when needed.
- Existing Web Viewer tabs remain unmanaged until manually reopened.
- Unsupported pages may remain in Original and show a native Notice.
- Automatic mode defaults ON. Turning it OFF does not exit native Reader.

### Verification

The release passed 138 automated tests, typecheck, and build. Native runtime checks were not rerun for the plugin-ID rename; historical native results do not validate this artifact. The native `-3` branch remains untested.
